🚂 KTZ Digital Twin | Smart Locomotive Dashboard
KTZ Digital Twin v1.0 — это высокотехнологичный full-stack прототип системы мониторинга и предиктивной диагностики локомотивов в реальном времени. Система позволяет отслеживать критические параметры состава, рассчитывать интегральный индекс здоровья (Health Index) и предотвращать аварийные ситуации до их возникновения.

✨ Ключевые особенности
Real-time Телеметрия: Частота обновления данных до 10 Гц через WebSockets для мгновенного реагирования.

Explainable AI (Health Index): Прозрачный расчет состояния локомотива (0-100%) на основе весовых коэффициентов 8 критических параметров.

Режим Replay & Trends: Анализ исторической выборки (до 900 сэмплов) для выявления деградации систем в динамике.

Интерактивная карта: Визуализация текущего положения состава с индикацией зон риска (Crit/Warn zones).

High-Load Simulator: Встроенный движок симуляции аномалий и перегрузок для стресс-тестирования системы.

🏗 Архитектура системы
Система построена на событийно-ориентированной модели (Event-Driven Architecture):

Telemetry Simulator (Node.js): Генерирует поток данных с учетом физических шумов и сценариев отказа (перегрев букс, падение давления в ТМ).

Logic Analyzer: Модуль нормализации, который сопоставляет сырые данные с порогами (Thresholds) и формирует рекомендации для машиниста.

WebSocket Gateway: Обеспечивает двустороннюю связь (рассылка метрик и прием команд управления нагрузкой).

Digital Twin UI (React + Tailwind): Адаптивный интерфейс с использованием ECharts для отрисовки графиков без потери производительности.

🚀 Инструкция по запуску
Предварительные требования
Node.js: v18.x или выше

npm: v9.x или выше

Способ 1: Локальный запуск
Установка зависимостей:

Bash
npm install
Запуск Backend-сервера:

Bash
node server.js
Запуск Frontend-приложения:

Bash
npm run dev
Доступ: Откройте http://localhost:5173. Код инженера: ktz2026.

Способ 2: Docker (Production-ready)
Bash
docker-compose up --build
📊 Мониторинг параметров
Система отслеживает следующие критические узлы:
| Параметр | Ед. изм. | Критический порог | Влияние на индекс |
| :--- | :--- | :--- | :--- |
| Engine Temp | °C | > 150°C | 35% |
| TM Pressure | bar | < 4.5 bar | 100% (Экстренное торможение) |
| Axle Temp | °C | > 90°C | 50% |
| Load Current| A | > 1500A | 40% |

🛠 Технологический стек
Frontend: React 18, TypeScript, Tailwind CSS, Lucide Icons.

Charts: Apache ECharts (echarts-for-react).

Backend: Node.js, Express, WS (WebSockets).

DevOps: Docker, EventEmitter API.

🛡 Безопасность
Доступ к дашборду ограничен слоем авторизации. Для входа в систему мониторинга требуется ввод 7-значного инженерного ключа. Все сессии и команды (например, переключение в режим High-Load) логируются на стороне сервера.
