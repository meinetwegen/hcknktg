## ✨ Особенности
- **Real-time Телеметрия**: Частота обновления до 10 Гц через WebSockets.
- **Индекс здоровья (Health Index)**: Интегральный показатель состояния (0-100) на основе 6 параметров.
- **Предиктивная диагностика**: Выявление критических зон (давление, температура) до отказа системы.
- **Безопасность**: Защищенный экран авторизации для инженерного состава.

## 🏗 Архитектура
Система построена на событийно-ориентированной модели (Event-Driven):
1. **Simulator**: Генерирует поток данных с учетом случайных шумов и "запланированных" аварий.
2. **Event Bus**: Внутренняя шина данных для обработки телеметрии без блокировок.
3. **Analyzer**: Модуль нормализации и расчета весовых коэффициентов индекса здоровья.
4. **WebSocket Server**: Рассылка обработанных данных подключенным клиентам.
